# EDA on Retail Sales Data

## Objective
Perform Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer behavior, and product performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- cleaned_retail_sales.csv

## Key Findings
- Monthly sales showed seasonal variations.
- Clothing category recorded the highest quantity sold.
- Price per unit had a strong positive correlation with total sales.
- Female customers were slightly higher than male customers.
- Electronics and Beauty categories had the highest average sales.

## Files
- EDA_Retail_Sales.ipynb
- cleaned_retail_sales.csv

## Conclusion
This project demonstrates how EDA can be used to understand sales patterns and generate business insights using Python.
